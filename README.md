# 等保刷题增强版

打开 `quiz.html` 刷题，`index.html` 保留原有条文背诵功能。纯静态，无依赖，可直接在本地打开，也可部署 GitHub Pages。

首批 30 题：22 道单选、8 道多选。依据 GB/T 22239-2019 第三级安全通用要求编写，非官方真题，也不是完整考试题库。2026-10-14 在国家标准官方平台核实现行状态；答案对照用户本地标准 PDF 的印刷页 28–32 逐条核对。题目包含条款号、页码、核对日期与官方查询链接。未直接导入来历或答案未核实的样卷及网上题库。

顺序/随机练习、章节和题型筛选、搜索、未练题、错题复练、收藏、答案解析、记录导入导出。多选完全一致计分。答对后移出待复练错题；历史累计准确率仍保留所有提交。跳过不计入正确率。组题后题目列表固定，筛选变更需重新开始。本地存储以网站和浏览器为单位，换设备需导出记录。导入相同题目以备份记录覆盖。

原有背诵材料未全量核对。本版修复已核对的“恶意代码防范/可信验证”控制点合并；文字覆盖度仅作参考，不能判定答案语义或替代考试阅卷。薄弱筛选使用最近成绩；筛选为空时随机按钮不会抽取范围外条文。

验证：JavaScript 语法、题库ID/答案索引/来源字段；浏览器单选计错、刷新保留记录、错题答对移出、多选少选判错、空范围提示。
